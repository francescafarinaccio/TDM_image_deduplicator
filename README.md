# TDM_image_deduplicator
Progetto di Trattamento Dati Multimediali 

Sistema modulare in Python per l'identificazione, la classificazione e la deduplicazione automatica di immagini basato su tecniche di elaborazione di dati multimediali.
Per poter eseguire l'applicazione assicurarsi di installare tutte le dipendenze contenute in requirements.txt
